# Contributing

Thank you for considering contributing to this project.

You can help by:

- Improving documentation
- Reporting bugs
- Testing tools in MetaTrader 5
- Adding usage examples
- Refactoring MQL5 code
- Adding comments to complex files
- Creating beginner-friendly guides

## Pull Request Guidelines

Before submitting a pull request:

1. Make sure the code compiles in MetaEditor.
2. Describe what the change does.
3. Mention whether the change affects indicators, scripts, Expert Advisors, or documentation.
4. Avoid adding strategies that promise guaranteed profits.

## Project Focus

The main focus of this repository is MetaTrader 5, MQL5 development, trading automation, indicators, scripts, and educational resources for algorithmic trading.
